I built an auto-responsive image gallery using CSS Grid that automatically adjusts columns without media queries. I collected 10 high-quality nature images from Unsplash including mountains, forests, oceans, lakes, and waterfalls, and placed each image inside a gallery-item div which acts as a card with border-radius, shadow, and an overlay showing the image title on hover. For the grid container, I used display grid and the key property grid-template-columns repeat auto-fit minmax 250px 1fr, which means the browser will automatically fit as many columns as possible that are at least 250px wide, and each column will grow equally to fill remaining space with 1fr, so on desktop it shows 4 columns, on tablet 2-3 columns, and on mobile 1-2 columns without writing any media queries. I applied width 100% and height 100% to all images so they fill their grid cells completely, and used object-fit cover which ensures images cover the entire area without stretching or distorting, cropping extra parts while maintaining aspect ratio, which is essential for a clean gallery look. I kept consistent spacing using gap 16px which gives uniform spacing both horizontally and vertically between all gallery items, much cleaner than margins. I verified that columns adjust automatically by changing the browser width: when I resized from 1200px desktop to 768px tablet to 400px mobile, the number of columns automatically reduced from 4 to 2 to 1, and grid-auto-rows 250px kept row heights consistent while two items span 2 rows using grid-row span 2 to create a masonry-like effect.
